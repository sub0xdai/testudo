# testudo-journal

## Performance Budget (PERF-01)
- Main entry chunk gzip budget: **250 KB** (FR-3, PERF-01).
- Run `bun run build:check` after any change that touches the cold path (imports in `index.tsx`, `config/wallet.ts`, `context/AuthContext.tsx`).
- `vendor-wallet` chunk is loaded lazily — only after the user clicks "Connect Wallet". Do not add top-level imports that pull `@reown/appkit` or `ethers` into the main bundle.
- SWR cache primitive lives in `src/lib/cache.ts` (`useCachedResource`, `invalidate`, `clearCacheForIdentity`, `stableHash`).

## Service Worker (PERF-02 CP-3)

The journal ships a hand-written service worker (~150 LOC, no Workbox) that precaches the app shell, applies NetworkFirst-with-3s-timeout to `/api/*`, and CacheFirst-30d to `*.woff2`. Default **off** — opt in via `VITE_ENABLE_SW=true`. Slated to flip default in CP-4 after a one-week canary.

### Files
- `public/sw.template.js` — source template with `__CACHE_NAME__` and `"[__SHELL__]"` placeholders.
- `scripts/inject-sw-shell.ts` — Vite plugin (`writeBundle` hook) that templates and emits `dist/sw.js`.
- `src/lib/sw-route.ts` — pure URL-classification helper, unit-tested in `sw-route.test.ts`. The SW inlines a copy of this exact logic; keep them in sync.
- `src/index.tsx` — registration block (deferred via `requestIdleCallback` / `setTimeout(2000)` fallback).

### Lifecycle
1. **install** — opens `caches.open(CACHE)`, `addAll(SHELL)` (precaches `/`, `/index.html`, the entry chunk, the main CSS), then calls `self.skipWaiting()` so the new worker activates without waiting for tab close.
2. **activate** — enumerates `caches.keys()`, deletes every cache whose name does not match the current `CACHE` constant (purges old `testudo-journal-vN` caches), then `self.clients.claim()` so the active worker takes over open tabs immediately.
3. **fetch** — branches via `classifyRequest(url, mode)`:
   - `bypass` (`?nosw=1` query) → no `respondWith` (browser handles natively).
   - `api` (`/api/*`) → `networkFirstWithTimeout(req, 3000)`. On timeout / network error, returns the cached response with a `sw-fallback: stale` header so the SPA cache layer can flag staleness.
   - `font` (`*.woff2`) → `cacheFirstWithTtl(req, 30d)`. TTL tracked via a `cached-at: <ms>` header injected on `cache.put`.
   - `navigate` (top-level navigation) → `cacheFirstShell(req)`. Falls back to `/index.html`, then `/` if the exact request is not cached.
   - `passthrough` → no `respondWith`.

### Cache-version bump procedure
1. Edit your deploy env (Cloudflare Pages, CI) or `.env.production` to set `VITE_SW_VERSION=vN+1`.
2. Build: `bun run build`. The Vite plugin templates `dist/sw.js` with `CACHE = 'testudo-journal-vN+1'`.
3. Deploy. On first navigation, the new worker installs (filling the new cache), then `activate` deletes the old `testudo-journal-vN` cache. Rolling deploys: at most one cache version per origin in the gap.
4. Hard rollback: redeploy a build with the previous `VITE_SW_VERSION` — old worker reactivates, deletes the newer cache.

### Manual user recovery (stale-shell trap mitigation)
If a user reports being pinned to a broken shell:

```js
// In DevTools console (any page on the origin):
navigator.serviceWorker.getRegistrations().then(r => r.forEach(x => x.unregister()))
caches.keys().then(k => Promise.all(k.map(n => caches.delete(n))))
// Then hard-reload the page (Ctrl+Shift+R / Cmd+Shift+R).
```

Document this in any user-support response touching a stale shell.

### `?nosw=1` debug flag
Append `?nosw=1` to any URL on the origin to bypass the service worker entirely for that request. Useful for diagnosing whether the SW is responsible for an observed bug. The flag flows through `classifyRequest` and short-circuits before any cache lookup or fetch interception.

### What is NOT cached
- POST/PUT/DELETE responses — explicitly skipped in `networkFirstWithTimeout`.
- Cross-origin opaque responses — the `cache.put` call is wrapped in `try/catch` so opaque-response failures don't break the fetch.
- Background sync, push, periodic sync — out of scope for the journal SW.
